# NCAA Basketball Simulator

A fictional college basketball head-coach dynasty simulator.

The human player controls one program through recruiting, roster management,
lineups, rotations, strategy, player development, scheduling, and in-game
coaching decisions. Persistent AI head coaches control competing programs with
distinct tactical and program-building identities.

Core product requirements include:

- deterministic, seeded basketball simulation
- simulation logic independent of React and browser APIs
- explicit shared TypeScript contracts
- reproducible games and AI decisions
- persistent, explainable AI coach behavior
- automated tests, type checking, linting, and production builds
